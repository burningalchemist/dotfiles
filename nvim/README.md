# Neovim

This directory contains `current` and `old` configurations for Neovim (mainly for historical reasons):

- `current` - The current configuration for Neovim, which is actively maintained and updated, based on the builtin
`vim.pack` package manager;

- `old` - The previous configuration for Neovim, which is no longer actively maintained but kept for reference and
historical purposes. It's based on `lazy.nvim` plugin manager and contains a different set of plugins and
configurations compared to the current setup.
