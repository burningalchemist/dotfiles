# dotfiles

**dotfiles** _(noun)_ - configuration files for various applications and tools, typically stored in a user's home
directory. They are used to customize the behavior and appearance of software, allowing users to maintain a consistent
environment across different systems.

---

This repository reflects my personal preferences and setup for various tools and applications. It generally covers
applications such as a terminal emulator, a text editor, a mail client, and some other utilities. It also contains the
list of applications and utilities to install via my current package manager. Overall, it's everything I may need to
set up a new system with my preferred configuration and tools.

Besides configuration files, the repository contains the key layouts and/or keyboard firmware for the mechanical
keyboards I own and use.
